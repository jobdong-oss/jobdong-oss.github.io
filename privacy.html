1. 앱의 목적

이 앱은 인덕원미래부동산중개가 직접 만든 부동산 뉴스 영상을 운영자 본인의 유튜브 채널에 업로드하고, 결과 파일을 운영자 본인의 구글 드라이브에 저장하기 위한 내부 자동화 도구입니다. 일반 사용자에게 제공되지 않으며, 운영자 본인 계정만 로그인합니다.

2. 이용하는 구글 사용자 데이터

  • YouTube Data API: 운영자 채널에 영상 업로드, 업로드한 영상 조회·관리
  • Google Drive API: 운영자 드라이브의 지정 폴더에 영상·문서 저장, 앱 전용 폴더에 작은 설정 파일 보관

다른 사람의 데이터는 수집하지 않습니다. 구글 사용자 데이터를 제3자에게 판매·공유·전송하지 않으며, 광고나 다른 목적으로 사용하지 않습니다.

3. 보관과 삭제

로그인 토큰은 운영자의 실행 환경에만 보관하며, 운영자가 언제든 구글 계정의 서드파티 앱 접근 설정에서 권한을 취소할 수 있습니다. 권한을 취소하면 앱은 더 이상 데이터에 접근하지 않습니다.

4. Google API 서비스 사용자 데이터 정책 준수

이 앱의 구글 API 데이터 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.
